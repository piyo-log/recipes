豆腐を混ぜた、やわらかいつくね。1回分ずつ分けやすいように、8個にして焼く。

## 材料

| 材料 | 分量 |
| --- | --- |
| 鶏ひき肉 | 150g |
| 木綿豆腐 | 100g（水切り前） |
| 玉ねぎ | 50g |
| 片栗粉 | 大さじ1 |
| サラダ油 | 小さじ1 |
| 蒸し焼き用の水 | 大さじ2 |
| たれ：しょうゆ | 小さじ1 |
| たれ：砂糖 | 小さじ1 |
| たれ：水 | 大さじ3 |

## 作り方

1. 豆腐をキッチンペーパーで包み、ざるにのせて10分ほど水を切る。玉ねぎは細かいみじん切りにする。
2. 玉ねぎを耐熱容器に入れ、ふんわりラップをして600Wのレンジで約1分30秒加熱する。しんなりしたら広げて冷ます。
3. ボウルに鶏ひき肉、豆腐、冷ました玉ねぎ、片栗粉を入れ、指先で手早く混ぜる。全体が均一になり、指を少し持ち上げると生地がくっついて短く伸びるような粘りを目安にする。8等分し、厚さ約1cmの小判形にする。
4. フライパンに油を引き、弱めの中火で片面を約3分焼く。裏返して水大さじ2を加え、ふたをして弱火で6〜8分蒸し焼きにする。中心温度75℃で1分以上を確認するまで加熱する。
5. たれの材料を混ぜて加え、ふたを外して弱火で1〜2分煮絡める。焦げつきそうなら少量の水を足す。

## 食べるとき

まずは2個を取り分け、食べやすく切って盛る。ごはんと副菜も添え、食べる量を見て調整したい。

## 作ってみた記録

冷凍のみじん切り玉ねぎで作ってみた。形は保てたけれど、自分で試食すると食感が少し柔らかすぎると感じた。混ぜ終わりの判断にも迷ったので、作り方に粘りの目安を追記した。

## 保存と温め直し

2個ずつを目安に、たれと一緒に浅い容器に分ける。当日〜翌日分は冷蔵し、残りはその日に冷凍して1週間で使う予定。

温めるときは耐熱皿に移し、水小さじ1を振ってふんわりラップをする。レンジで途中に裏返し、中心まで75℃以上に温める。保存の手順は[作り置きのメモ]({{< relref "/recipes" >}}#作り置きのメモ)にまとめた。
