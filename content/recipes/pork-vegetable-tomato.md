和風のおかずが多いので、トマト味も1品入れてみたい。野菜を小さく切って、スプーンですくいやすくする。

## 材料

| 材料 | 分量 |
| --- | --- |
| 豚ひき肉 | 160g |
| にんじん | 60g |
| なす | 80g |
| 玉ねぎ | 60g |
| カットトマト缶（食塩無添加） | 200g |
| 水 | 100ml |
| サラダ油 | 小さじ1 |
| しょうゆ | 小さじ1 |
| 砂糖 | 小さじ1/2 |

## 作り方

1. 玉ねぎとにんじんは5mmほどのみじん切りにする。なすは皮をむき、1cm角に切る。
2. 小鍋か深めのフライパンに油を引き、玉ねぎとにんじんを弱めの中火で2〜3分炒める。
3. 豚ひき肉を加え、大きな塊を崩しながら炒める。肉の色が変わったら、なすを加えてさらに2分ほど炒める。
4. トマト缶、水、しょうゆ、砂糖を加える。煮立ったらふたを少しずらし、弱火で15〜20分、時々混ぜて煮る。肉を含めて中心温度75℃で1分以上加熱し、にんじんがやわらかくなるまで煮る。
5. 汁気が多ければふたを外して少し煮詰め、具と汁が一緒にすくえるくらいにする。途中で水分が足りなくなったら、水を少しずつ足す。

## 食べるとき

まずは小さな器に取り分けて、ごはんと一緒に。余裕がある日は、短く切ったゆでうどんに合わせるのも試してみたい。

## 保存と温め直し

4回分を目安に浅い容器に分ける。当日〜翌日分は冷蔵し、残りはその日に冷凍して1週間で使う予定。

温め直しは小鍋かレンジで。焦げつきそうなら水を少し足し、底から混ぜて中心まで75℃以上に温める。[作り置きのメモ]({{< relref "/recipes" >}}#作り置きのメモ)も参照。
