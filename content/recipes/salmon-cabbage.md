鮭をほぐしてキャベツと一緒に食べられる、汁気のある主菜にしたい。

## 材料

| 材料 | 分量 |
| --- | --- |
| 生鮭（塩をしていないもの） | 160g（皮と骨を除く） |
| キャベツ | 120g |
| だし汁（食塩無添加） | 200ml |
| しょうゆ | 小さじ1 |
| 砂糖 | 小さじ1/2 |
| 水溶き片栗粉：片栗粉 | 小さじ1 |
| 水溶き片栗粉：水 | 小さじ2 |

## 作り方

1. 鮭の皮と骨を取り除き、2cmほどに切る。キャベツの葉は1cm幅に、厚い芯は薄く切る。
2. 小鍋にだし汁とキャベツを入れる。煮立ったらふたをして、弱火で7〜8分煮る。
3. 鮭、しょうゆ、砂糖を加え、ふたをして弱火でさらに6〜8分煮る。鮭は中心温度75℃で1分以上を確認するまで加熱し、キャベツもスプーンで切れるやわらかさにする。煮汁が減ったら水を少し足す。
4. 鮭を粗くほぐし、骨が残っていないかもう一度見る。水溶き片栗粉を混ぜ直して加え、全体を混ぜながら1分ほど煮る。

## 食べるとき

鮭とキャベツが偏らないように取り分け、煮汁も少し添える。ほぐした鮭の大きさは、食べる様子に合わせて小さくする。

## 保存と温め直し

4回分を目安に、煮汁ごと浅い容器に分ける。当日〜翌日分は冷蔵し、残りはその日に冷凍して1週間で使う予定。

レンジで温めるときは、電子レンジ対応の容器でふんわりラップをし、途中で混ぜる。中心まで75℃以上に温め、汁気が足りなければ水を小さじ1ずつ加える。[作り置きのメモ]({{< relref "/recipes" >}}#作り置きのメモ)も参照。
