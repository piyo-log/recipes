玉ねぎとキャベツをほかの料理にも使うので、その流れでスープも用意しておきたい。今回はしめじを細かく刻んで入れる。

## 材料

| 材料 | 分量 |
| --- | --- |
| 玉ねぎ | 100g |
| キャベツ | 100g |
| しめじ | 40g（石づきを除く） |
| だし汁（食塩無添加） | 500ml |
| しょうゆ | 小さじ1 |

## 作り方

1. 玉ねぎは長さ1cmほどの薄切りにする。キャベツの葉は1cm角、厚い芯は薄切りにする。
2. しめじは石づきを取り、かさも軸も5mmほどに細かく刻む。
3. 小鍋にだし汁と具材を入れて中火にかける。煮立ったら弱火にし、ふたを少しずらして15分ほど煮る。
4. 玉ねぎとキャベツがやわらかくなったら、しょうゆを加えてひと煮立ちさせる。煮詰まっていれば水を少し足す。

## 食べるとき

具と汁を一緒に、小さな汁椀へ。きのこは弾力があるので、かみ切りにくそうならさらに細かくする。ごはんや主菜の量に合わせて、スープは少しから出してみたい。

## 保存と温め直し

5回分を目安に、浅い容器へ具と汁を均等に分ける。当日〜翌日分は冷蔵し、残りはその日に冷凍して1週間で使う予定。冷凍用の容器は、膨らむ分の余裕を残して入れる。

小鍋で温めるときは、底から混ぜて全体を沸騰させる。レンジなら電子レンジ対応の容器に移し、ふんわりラップをして途中で混ぜ、中心まで75℃以上に温める。冷却の手順は[作り置きのメモ]({{< relref "/recipes" >}}#作り置きのメモ)にまとめた。
