[鮭とキャベツの煮物]({{< relref "/recipes/salmon-cabbage" >}})を考えていたけれど、ピヨちゃんには焼く方が合いそうな気がして、鮭に焼き目をつける料理を試してみることにした。

参考レシピのアスパラは家にないので、キャベツで代用する。鮭を先に焼いて取り出し、野菜に火を通してから戻す。

## 材料

| 材料 | 分量 |
| --- | --- |
| 生鮭（塩をしていないもの） | 160g（皮と骨を除く） |
| じゃがいも | 200g（皮をむいた重さ） |
| キャベツ | 120g |
| にんにく | 2g（小さめ1/2片を目安に） |
| 片栗粉 | 小さじ2 |
| サラダ油 | 小さじ1 |
| バター | 10g（5gずつに分ける） |
| しょうゆ | 小さじ1と1/2（下味に小さじ1/2、仕上げに小さじ1） |
| 水 | 大さじ2（じゃがいもの下加熱とキャベツに、大さじ1ずつ） |

## 作り方

1. じゃがいもは皮をむき、厚さ約1cmの半月切りにして水にさらす。キャベツの葉は1cm幅、硬い芯は薄切りにする。にんにくは細かく刻む。
2. じゃがいもの水気を切り、耐熱皿に重なりすぎないように並べる。水大さじ1を加え、ふんわりラップをして600Wのレンジで3〜4分加熱する。竹串がすっと通るまで、足りなければ30秒ずつ追加する。皿に残った水は切る。
3. 鮭の皮と骨を取り除き、厚さ約1cmのひと口大のそぎ切りにする。水気をふき、しょうゆ小さじ1/2を絡めて、片栗粉を薄くまぶす。
4. フライパンにサラダ油とバター5gを入れ、弱めの中火で熱する。鮭を並べ、片面を約3分焼く。裏返して弱火にし、さらに3〜4分を目安に焼く。中心温度75℃で1分以上を確認するまで加熱し、清潔な皿に取り出す。
5. 同じフライパンに残りのバター5gとにんにくを入れ、弱火で香りが出るまで約30秒炒める。じゃがいもとキャベツを加え、弱めの中火で1〜2分炒める。水大さじ1を加えてふたをし、弱火で3〜4分、キャベツの芯をスプーンで切れるやわらかさになるまで加熱する。
6. ふたを外し、余分な水気を飛ばす。鮭を戻し、しょうゆ小さじ1を鍋肌から加える。鮭を崩しすぎないように、1分ほど軽く炒め合わせる。

## 食べるとき

鮭・じゃがいも・キャベツをそれぞれ4等分するつもりで取り分け、ごはんや副菜も添える。鮭はもう一度骨を確認して食べやすくほぐし、じゃがいもとキャベツも、必要に応じて小さく切る。

盛り付けるときは鮭と野菜を分けて並べ、どれを食べるか見てみたい。

一度作ってみたところ、ピヨちゃんは鮭とじゃがいもを食べてくれた。[食べたときの記録]({{< relref "/posts/first-salmon-butter-soy" >}})も残している。

## 保存と温め直し

食卓に出す前に、清潔な器具で4回分を目安に浅い容器へ分ける。当日〜翌日分は冷蔵し、残りはその日に冷凍して1週間で使う予定。

温めるときは耐熱皿に移し、水小さじ1を振ってふんわりラップをする。途中で鮭を裏返し、野菜の位置も変えて、中心まで75℃以上に温める。冷却と解凍の手順は[作り置きのメモ]({{< relref "/recipes" >}}#作り置きのメモ)にまとめた。

じゃがいもの食感は、冷凍して温め直したあとにも確認したい。
