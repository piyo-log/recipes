味付けをいろいろ足す前に、かぼちゃの甘さで食べてくれるか試してみたい。

## 材料

| 材料 | 分量 |
| --- | --- |
| かぼちゃ | 250g（種とわたを除く） |
| 水 | 180ml |
| 砂糖 | 小さじ1 |
| しょうゆ | 小さじ1/2 |

## 作り方

1. かぼちゃの種とわたを取り、硬い皮をそぎ落とす。2〜3cm角に切る。
2. 小鍋にかぼちゃを重ならないように並べ、水と砂糖を入れる。水はかぼちゃの高さの半分ほどを目安に、鍋に合わせて少し足す。
3. 火にかけ、煮立ったら弱火にする。ふたを少しずらして、8分ほど煮る。
4. しょうゆを加え、さらに3〜5分煮る。スプーンで軽く押してつぶせるやわらかさになったら火を止める。途中で煮汁がなくなりそうなら水を足し、鍋の中を強くかき混ぜない。

## 食べるとき

皮が硬ければ取り除き、食べやすい大きさに分けて盛る。口の中でぱさつくようなら、煮汁を少し加えて粗くつぶす。

## 保存と温め直し

6回分を目安に、少量の煮汁と一緒に分ける。当日〜翌日分は冷蔵し、残りはその日に冷凍して1週間で使う予定。

レンジでは水を少し振ってふんわりラップをし、途中で位置を変えて温める。冷凍後に崩れたら、そのままつぶして小鉢にしてみたい。冷却と再加熱の手順は[作り置きのメモ]({{< relref "/recipes" >}}#作り置きのメモ)にまとめた。
