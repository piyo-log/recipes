豚ヒレのブロックと、家にあるまいたけで、焼く主菜を作ってみたい。

豚ヒレに片栗粉を薄くまぶして焼き、炒めたまいたけと合わせる。しょうゆとみりんを絡め、最後にバターを加えて、ピヨちゃんの食べ具合を見てみたい。

## 材料

| 材料 | 分量 |
| --- | --- |
| 豚ヒレ肉（ブロック） | 200g（硬い筋や膜を除いた重さ） |
| まいたけ | 100g（硬い根元があれば除いた重さ） |
| 片栗粉 | 小さじ2 |
| サラダ油 | 小さじ1（小さじ1/2ずつに分ける） |
| バター | 5g |
| しょうゆ | 小さじ2 |
| みりん | 小さじ2 |
| 水 | 大さじ1（豚肉の蒸し焼き用）／温め直し用に1回分につき小さじ1 |

## 作り方

1. まいたけは硬い根元があれば除き、ほぐす。長い部分は1〜2cm程度に切る。しょうゆとみりんを混ぜておく。
2. 豚ヒレの表面に硬い筋や膜があれば除く。ブロックの端から1cm厚さに切り、軽くたたいて厚さ7〜8mm程度にそろえる。水気を拭き、片栗粉を薄くまぶす。
3. フライパンにサラダ油小さじ1/2を入れて中火で熱し、まいたけを3〜4分、しんなりするまで炒めて清潔な皿に取り出す。
4. 残りのサラダ油小さじ1/2を加え、豚肉を重ならないように並べる。中火で2〜3分、焼き目がつくまで焼く。
5. 裏返して水大さじ1を加え、ふたをして弱火で3〜4分を目安に加熱する。中心温度75℃で1分以上を確認するまで加熱する。
6. ふたを外し、余分な水分を飛ばす。まいたけを戻し、混ぜておいたしょうゆとみりんを加えて、弱めの中火で1〜2分煮絡める。最後にバターを加え、溶けて全体に絡んだら火を止める。

## 食べるとき

豚ヒレとまいたけをそれぞれ4等分するつもりで取り分け、ごはんや副菜も添える。

豚ヒレは焼いた後、清潔な包丁・まな板でピヨちゃんが食べやすい大きさに切る。まいたけも噛み切りにくそうな部分はさらに短く切る。

## 保存と温め直し

食卓に出す前に、清潔な器具で4回分を目安に浅い容器へ分ける。当日〜翌日分は冷蔵し、残りは作った日に冷凍して1週間で使う予定。

温めるときは耐熱皿に移し、水小さじ1を振ってふんわりラップをする。途中で豚肉を裏返し、まいたけの位置も変えて、中心まで75℃以上に温める。冷却と解凍の手順は[作り置きのメモ]({{< relref "/recipes" >}}#作り置きのメモ)にまとめた。
