鶏もも肉を使った、焼く主菜を作ってみたい。野菜は小松菜を合わせる。

鶏肉に焼き目をつけてからいったん取り出し、小松菜をやわらかくして戻す。しょうゆとみりん、少しの砂糖で味をつけ、ピヨちゃんの食べ具合を見てみたい。

## 材料

| 材料 | 分量 |
| --- | --- |
| 鶏もも肉 | 200g（皮付き、余分な脂を除いた重さ） |
| 小松菜 | 100g（根元を除いた重さ） |
| サラダ油 | 小さじ1/2 |
| しょうゆ | 小さじ1 |
| みりん | 小さじ1 |
| 砂糖 | 小さじ1/2 |
| 水 | 大さじ1（小松菜の蒸し焼き用）／温め直し用に1回分につき小さじ1 |

## 作り方

1. 小松菜をよく洗い、茎と葉に分ける。茎は5mm〜1cm、葉は1cm幅程度に切る。しょうゆ・みりん・砂糖を混ぜておく。
2. 鶏肉の余分な脂を除き、厚い部分を包丁で開いて厚みを約1cmにそろえる。4つ程度に切り、キッチンペーパーで水気を拭く。
3. フライパンにサラダ油を入れて中火で熱し、鶏肉を皮側から3〜4分焼く。裏返してふたをし、弱火で4〜6分を目安に加熱する。中心温度75℃で1分以上を確認するまで加熱し、清潔な皿に取り出す。
4. 同じフライパンの余分な脂を拭き取り、小松菜の茎を弱めの中火で約1分炒める。水大さじ1を加えてふたをし、弱火で2〜3分蒸し焼きにする。
5. 葉を加え、再びふたをして弱火で1〜2分加熱する。茎をスプーンで切れるやわらかさになるまで、足りなければ追加で加熱する。
6. ふたを外し、余分な水気を軽く飛ばす。鶏肉を戻し、混ぜておいた調味料を加える。弱めの中火で2〜3分を目安に絡め、焦げそうなときは火を弱める。

## 食べるとき

鶏肉と小松菜をそれぞれ4等分するつもりで取り分け、ごはんや副菜も添える。

鶏肉は清潔な包丁・まな板で、ピヨちゃんが食べやすい大きさに切る。皮が噛みにくそうなら取り除き、小松菜も必要に応じてさらに短く切る。

盛り付けるときは肉と小松菜を分けて並べ、それぞれの食べ具合を見てみたい。

## 保存と温め直し

食卓に出す前に、清潔な器具で4回分を目安に浅い容器へ分ける。当日〜翌日分は冷蔵し、残りは作った日に冷凍して1週間で使う予定。

温めるときは耐熱皿に移し、水小さじ1を振ってふんわりラップをする。途中で鶏肉を裏返し、小松菜の位置も変えて、中心まで75℃以上に温める。冷却と解凍の手順は[作り置きのメモ]({{< relref "/recipes" >}}#作り置きのメモ)にまとめた。
